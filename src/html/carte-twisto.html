À propos du projet

Cette carte interactive présente l'ensemble du réseau de transport en commun TWISTO de Caen. Développée avec Python pour l'analyse des données GTFS et Leaflet.js pour la visualisation web, elle permet d'explorer facilement les 2093 arrêts du réseau.

Technologies utilisées

  • Python: Analyse des données GTFS avec Pandas
  • Folium: Génération des cartes interactives
  • Leaflet.js: Affichage web optimisé
  • JavaScript ES6+: Interactivité avancée

Fonctionnalités

  • 🔍 Recherche d'arrêts en temps réel
  • 🗺️ 2 styles de carte différents
  • Popups informatifs détaillés
  • 📱 Interface responsive
  • ⛶ Mode plein écran
