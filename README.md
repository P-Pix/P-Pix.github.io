# Guillaume Lemonnier - Site personnel et portfolio

## Positionnement

Site personnel présentant un profil à l'interface entre :

- l'IA appliquée à la santé,
- les données sensibles et les contraintes de déploiement,
- la recherche en apprentissage automatique,
- l'ingénierie logicielle et les outils métiers.

Le site est désormais pensé pour refléter un profil **déjà en poste**, crédible pour des échanges avec des entreprises,
des équipes R&D et des encadrants de thèse, plutôt qu'une simple logique de recherche active d'emploi.

## Contenu principal

- **Accueil** : synthèse du profil, des expériences récentes et des axes de travail.
- **Projets** : sélection éditorialisée de dépôts GitHub et démonstrateurs web.
- **CV** : version web alignée avec le CV PDF récent.
- **Positionnement** : page dédiée aux opportunités ciblées, collaborations R&D et perspectives doctorales.
- **Associatif** : responsabilités et engagement.
- **Pages d'expertise** : détail des domaines techniques.

## Références de fond intégrées dans la refonte

Le contenu éditorial s'aligne notamment avec :

- le poste actuel à l'ARS Normandie ;
- le stage de recherche au GREYC sur l'explicabilité des GNN ;
- les axes de recherche en apprentissage fédéré, imagerie longitudinale, explicabilité et robustesse ;
- la publication co-signée à IDA 2026 ;
- le portfolio GitHub et les démonstrateurs web déjà présents dans le projet.
