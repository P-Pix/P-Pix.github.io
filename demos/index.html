03 / PERFORMANCE & BACKPRESSURE

Enregistreur binaire

Faites varier le nombre d'événements et la capacité d'une file bornée. Explorez la saturation en mode try_push non bloquant et les événements consommés.

FILE BORNEE
EN ATTENTE0 / 8file bornée
TRAITES0événements consommés
REFUSES0try_push non bloquant
FILE PRODUCTEUR / CONSOMMATEUR0% OCCUPATION

File prête : lancez une rafale.

Ce qui tourne en C++ : structure circulaire, borne de capacité, ordonnancement FIFO et comptage. Il s'agit d'un modèle séquentiel explicatif, pas d'un benchmark ni de l'enregistreur multithread complet. Dans le projet original, AsyncRecorder::submit() est bloquant lorsque la file est pleine.

A propos de cette demonstration

Des limites annoncées.
